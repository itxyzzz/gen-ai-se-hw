## Overview

This homework builds a deterministic Python transaction-processing pipeline from an AI-generated specification, code package, test package, and documentation package. The runtime system reads the eight synthetic transactions in `sample-transactions.json`, passes safe JSON messages through the required `shared/` protocol folders, and writes final results under `shared/results/`.

The pipeline is an educational simulation only. It does not move money, contact payment networks, perform sanctions screening, verify identities, make legal or banking decisions, or claim real AML, KYC, PCI, settlement, fraud, or payment-network compliance.

## Automation Agents

- Athena (Spec Writer): produced the selected Python transaction-system specification in `specification.md`.
- Hephaestus (Code Generator): generated the selected Python runtime components, JSON file protocol implementation, and Context7 research notes.
- Themis (Test Generator): generated and selected the test package that validates runtime behavior, privacy constraints, command support, hook behavior, and MCP reader surfaces.
- Clio (Documentation Generator): generated this reviewer-facing documentation package and the PR draft from the selected spec/code/test records.

## Runtime Pipeline Agents

- Integrator: prepares `shared/`, archives prior runs, loads the sample records, writes provenance, orchestrates components, and summarizes results.
- Transaction Validator: validates required fields, positive `Decimal` amounts, supported currencies, timestamps, and validation-only dry runs.
- Fraud Detector: applies deterministic educational risk scoring and assigns low, medium, or high risk.
- Settlement Processor: produces final simulated statuses: `settled`, `rejected`, `review_required`, or `error`.
- Pipeline Status MCP Server: reads existing result files through safe tools and a `pipeline://summary` resource without rerunning the pipeline.

## Current Limits

- The project is intentionally file-based and local-only.
- The MCP server reads current result files; it does not run the pipeline.
- Screenshots were copied from preserved operator-sourced evidence. Some screenshots show an earlier 41-test count, while fresh Clio text evidence records the current 50-test suite and 94.79% coverage.
- Plain `from mcp.server ...` can resolve to an installed third-party `mcp` package in this environment; tests and Clio evidence load the local server by file path when direct helper imports are needed.

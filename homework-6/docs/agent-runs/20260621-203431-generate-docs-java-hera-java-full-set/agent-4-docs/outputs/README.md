## Overview

This Java candidate implements the Homework 6 banking-pipeline assignment as a Maven project. It reads the eight synthetic records in `sample-transactions.json`, moves JSON messages through the required `shared/` file protocol, validates records, applies deterministic educational risk scoring, produces simulated settlement outcomes, and writes safe result summaries.

The project is an educational simulation only. It does not move money, contact payment networks, screen sanctions, verify identity, provide legal advice, or claim real banking, AML, KYC, PCI, settlement, fraud, or payment-network compliance.

## Runtime Components

- `Integrator`: prepares `shared/`, archives previous output, writes run provenance, loads sample transactions, invokes runtime components, and finalizes summaries.
- `TransactionValidator`: validates required fields, timestamps, positive `BigDecimal` amounts, supported currencies, and validation-only behavior.
- `FraudDetector`: applies deterministic educational risk scoring for amount, timing, channel, country, and transfer type.
- `SettlementProcessor`: maps validated and risk-scored messages to `settled`, `rejected`, `review_required`, or `error`.
- `ReportingAgent`: writes one safe `TXN*.json` result per input plus `summary.json` and `pipeline-status.json`.
- `pipeline-status` MCP reader: the existing Python FastMCP server can read Java candidate result shapes for core safe fields when pointed at candidate results or when Java results are staged under root `shared/results`.
